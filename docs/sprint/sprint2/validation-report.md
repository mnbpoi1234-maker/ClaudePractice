**게임 플레이:**
- ⬜ 숫자 2에서 "숫자외치기" → 정상 진행
- ⬜ 숫자 3에서 컴퓨터가 "/박수/" 수행 → 숫자 4로 진행
- ⬜ 숫자 2에서 "박수" → 게임 종료

**타이머 (난이도별):**
- ⬜ 쉬움 (5초) - 타이머 카운트다운 표시 및 시간 초과 시 종료

- ⬜ 어려움 (1초) - 빠른 시간 초과 처리

**키보드 단축키:**
- ⬜ 사용자 턴에서 `a` 키 → "숫자외치기" 동작
