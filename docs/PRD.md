369게임의 정의와 요구사항이 작성된 문서입니다.

# 프로젝트명
369 게임

# 369게임의 정의
n명의 사람이 참여하는 게임. 한 명씩 번갈아가며 숫자를 1씩 증가시키며 그 값을 외친다. 1부터 시작한다. 단 숫자에 3, 6, 9가 들어가있을 경우, 3,6,9가 포함된 횟수만큼 박수를 친다.
위 조건에 수행하지 않는 사람이 지는 게임이다.

# 프로젝트 목표
369 게임을 React와 TypeScript를 이용하여 구현한다.
단, 사용자가 한 명인 게임으로 구현하며, 컴퓨터와 대결을 한다.

# 요구사항
1. 기능 요구사항
   1. 게임 진행
      1. 숫자는 1부터 시작한다.
      2. 컴퓨터가 무조건 먼저 진행하며, 사용자와 1회씩 번갈아가며 진행한다.
      3. 컴퓨터는 무조건 올바른 게임 규칙만 수행한다.
      4. 현재 숫자에 대한 사용자와 컴퓨터의 행위가 표기되어야한다. 숫자 외치기는, 현재 숫자를 표기하며, 박수는 1회당 "/박수/" 텍스트를 표기한다.
      5. 컴퓨터가 수행한 올바른 행위를 표기한다.
      6. 사용자가 잘못된 입력을 했을 경우, 현재 숫자 표시에 "게임 종료"라는 텍스트를 표기한다.
   2. 난이도 설정
      1. 난이도에 따라 사용자가 답변해야하는 시간 제한이 달라진다.
      2. 난이도는 쉬움, 보통, 어려움 3단계이다.
      3. 난이도의 기본값은 보통이다.
      4. 난이도 쉬움은 5초, 보통은 3초 어려움은 1초 내에 올바른 행동을 해야한다.
   3. 리셋
      1. 게임의 진행도와 관계없이, 게임을 다시 시작한다.
2. UI
   1. UI 기본 규칙
      1. 모든 컨트롤의 위치는 viewport의 상대값이 변경되면 안 된다.
      2. 모든 컨트롤의 Font는 맑은 고딕으로 지정한다.
      3. 버튼은 가로 100px, 세로 50px으로 사이즈를 고정한다.
      4. 현재 숫자를 표기하는 컨트롤의 글자 크기는 25로 지정한다.
   2. 게임 UI
      1. 현재 숫자에 해당하는 값은 페이지 가운데 배치한다.
      2. 현재 행위를 표기하는 텍스트는 숫자 밑에 배치한다.
      3. 숫자 외치기와 박수를 대체할 버튼 2개를 생성하며, 가로로 배치한다. 현재 행위를 표기하는 텍스트 아래에 배치한다.
      4. 버튼의 사이즈는 가로 100px, 세로 50px로 지정한다.
      5. 숫자외치기 버튼의 단축키는 a, 박수 버튼의 단축키는 l로 지정한다.
   3. 설정 UI
      1. 난이도 쉬움, 보통, 어려움에 해당하는 버튼 3개를 생성하며, 이 버튼들은 가로로 배치시킨다.
      2. 난이도 버튼은 페이지 우측 상단에 지정한다.
      3. 게임을 리셋할 수 있는 버튼을 생성한다.
      4. 리셋 버튼은 난이도 어려움 버튼 하단에 위치시킨다.
